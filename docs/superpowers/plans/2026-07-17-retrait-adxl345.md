# Retrait des 2× ADXL345 + feature Courses ALT — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retirer intégralement les deux accéléromètres ADXL345 (tube `0x53`, monture `0x1D`) et la feature « Courses ALT min/max » du backend, de l'app Flutter et des docs/schémas — sans casser le compass LIS3MDL ni le GPS, qui restent.

**Architecture :** Suppression chirurgicale. Les fichiers **propres à l'ADXL** (adapter, `_bias_fit`, écrans ADXL, feature limits) sont supprimés ; les fichiers **partagés avec le compass** (service de calibration, repo, modèles, `CalibrationBloc`, `compass_stream`, `_tilt_compensated_heading`) sont **édités** pour retirer les branches ADXL et laisser le compass fonctionner en heading **non tilt-compensé** (fallback `naive_heading` déjà présent). Le compass conserve toute sa correction hard/soft-iron (LIS3MDL) ; il perd seulement la compensation d'assiette, ce qui est attendu (la source ADXL disparaît).

**Tech Stack :** Backend FastAPI / Python 3.13 (uv, pytest, aiosqlite/SQLite). App Flutter (flutter_bloc, mocktail). Docs Markdown + schémas HTML/SVG statiques.

## Décisions actées (baked-in, ne pas re-débattre en exécution)

Issues de la discussion ayant produit ce plan :

1. **Compass en heading non tilt-compensé.** `compass_stream` appelle désormais toujours `naive_heading()`. La compensation d'assiette (source ADXL monture) disparaît. Le plate-solve (Macro 5) fournira le pointage précis — cf. ADR 2026-05-10 et backlog. Acceptable.
2. **Courses ALT supprimées, pas re-sourcées.** L'enforcement n'a jamais existé (seul un `# TODO v0.3` dans `slew()`). L'anti-collision réel sera reconstruit en Macro 3 (GoTo, référencé position monture). Rien à re-sourcer aujourd'hui.
3. **Mise à niveau = bulle physique.** La bulle virtuelle (ADXL monture) disparaît ; le niveau à bulle physique devient la seule méthode. L'alignement alt-az absorbe le tilt résiduel de toute façon.
4. **Gating alignement sur « tilt level » supprimé.** Le wizard 3 étoiles ne conditionne plus rien à « monture de niveau » (c'était doc-only ; à re-vérifier en Task 1, étape 0).

## Global Constraints

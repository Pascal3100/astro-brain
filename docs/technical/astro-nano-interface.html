Interface single-wire « dédoubleur » sur Arduino Nano

Le Nano fait tout : open-drain propre + séparation TX/RX. Plus de diode, plus de pull-up externe.

TX dongle → D2 D3 → RX dongle D4 ↔ DATA (bus) +5V (dongle → Nano) GND commun

Firmware (Nano) — ~15 lignes

// Dédoubleur single-wire complet — aucun composant passif
// D2 <- TX dongle | D3 -> RX dongle | D4 <-> DATA monture (open-drain + pull-up interne)
void setup() {
  DDRD  &= ~(1 << 2);                       // D2 entrée  (TX dongle)
  DDRD  |=  (1 << 3);                       // D3 sortie  (RX dongle)
  DDRD  &= ~(1 << 4);  PORTD |= (1 << 4);   // D4 input + pull-up interne -> bus haut au repos
}
void loop() {
  if (PIND & (1 << 2)) {                    // TX haut (repos)
    DDRD  &= ~(1 << 4);  PORTD |= (1 << 4); //   relâche : input + pull-up
  } else {                                  // TX bas
    PORTD &= ~(1 << 4);  DDRD  |= (1 << 4); //   drive 0V franc (open-drain)
  }
  if (PIND & (1 << 4))  PORTD |= (1 << 3);  // bus -> RX dongle
  else                  PORTD &= ~(1 << 3);
}

Le Nano ne tire le bus bas que quand le TX du dongle est bas (open-drain, 0V franc ~0,1V) ; sinon il relâche (Hi-Z + pull-up). Le bus est recopié vers le RX. L'écho revient toujours — indi_celestron_aux le filtre.

Câblage — Nano + 5 fils, rien d'autre

  • ● dongle TX → D2
  • ● Nano D3 → RX dongle
  • ● Nano D4 ↔ DATA monture (broche 4)
  • ● dongle 5V → pin « 5V » du Nano (l'alimente, pas de 2ᵉ câble USB)
  • ● GND commun : dongle + Nano + monture (broche 5)

On retire : la diode 1N4007 et la pull-up 4.7k externe — le Nano fait tout.
⚠️ Tout en 5V · GND commun obligatoire · +12V (br.3) jamais branché.

Validation

  • 1. Câble + flashe le Nano.
  • 2. Niveau bas (break-test) : DATA↔GND doit tomber à ~0,1–0,2V (contre 0,97V avec la 1N4007). C'est le critère électrique. ✓
  • 3. GET_VER : si la monture répond (octets en plus de l'écho) → gagné.
  • Caveat front montant : la pull-up interne du Nano est faible (~30–50 kΩ). Si le GET_VER est flaky/intermittent, le front 0→1 est trop mou sur le câble → ajoute une seule résistance pull-up externe (1k–4.7k vers +5V sur DATA). Le niveau bas, lui, restera parfait.

Schéma

Netlist (ordre de câblage)

  • 1TX dongle → Rb1 → base Q1
  • 2collecteur Q1 → Rc → +5V
  • 3collecteur Q1 → Rb2 → base Q2
  • 4émetteurs Q1 & Q2 → GND
  • 5collecteur Q2 → ligne DATA
  • 6DATA → Rpu → +5V
  • 7DATA → RX dongle & RJ-12 broche 4
  • 8GND commun : dongle, RJ-12 broche 5, émetteurs

Brochage TO-92 BC547  ·  ⚠ C-B-E (pas E-B-C)

Confirmé au multimètre : rouge sur la patte du milieu → ~0,9 V des deux côtés = base centrale + NPN. ✓

Avant mise sous tension

Orientation RJ-12 : repérer le +12 V (broche 3) au multimètre, monture allumée, avant tout branchement. Un câble RJ-12 reversed inverse tout l'ordre — un +12 V sur le dongle le grille, voire le port USB du Pi.
Sélecteur dongle CP2102 sur 5 V, pas 3,3 V.
GND commun obligatoire entre le dongle, le montage et la broche 5 du RJ-12, sinon la masse flotte et le bus est erratique.
